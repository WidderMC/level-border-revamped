**Adds a border that expands as you level up. Playable with friends!**

## ⚠️ Warning

Once you enable this mod in a world, there is no going back, and you cannot change any settings. This is designed to prevent cheating.

I strongly recommend using this mod in a separate mod profile to avoid accidentally enabling it in your regular worlds.

If you accidentally enable the mod in a world, feel free to join my [Discord](https://discord.gg/fy4KuxYKVD), and I'll try to help you fix it. However, I cannot guarantee that I'll be able to recover your world.

## Level = Border Revamped

A mod that lets you and your friends play **Level = Border** together!

### Features
- Synchronised XP and levels
- The border shrinks when someone spends XP (e.g. on an anvil or enchanting table)
- Safety switch for regular worlds
- Lots of configurable settings

## List of all subcommands for `/Level-Border`

| Setting | Description | Default Value |
| -------- | ----------- | ------------- |
| `EnableMod` | Enables the mod. To prevent accidental activation, you have to confirm it with `/Level-Border EnableMod confirm`. Once enabled, it can't be disabled and the settings can no longer be changed. | `false` |
| `ResetBorderByDeath` | Resets the border to its start size when a player dies. Only works if `ResetXPByDeath` is enabled. | `false` |
| `ResetXPByDeath` | Resets the shared XP of all players to 0 when a player dies. | `true` |
| `AutoExpand` | The border grows automatically when the players level up. If disabled, use `/Level-Border Expand` to expand it manually. | `true` |
| `OriginalNetherBorder` | If enabled, the Nether border is 1/8 of the Overworld border size (like Nether coordinates). If disabled, it has the same size as the Overworld border. | `true` |
| `Expand` | Expands the border to the current level of the players. Only works if `AutoExpand` is disabled. |  |
| `StartSize` | The size of the border in blocks at level 0. | `1` |
| `BlocksPerLevel` | How many blocks the border grows per level. | `1` |
